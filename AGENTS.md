# Project rules

- Travel Connection may seed advertised cup fixtures and explicitly offered Scottish home fixtures missing from schedule feeds; match within the competition first and use stable supplier IDs to prevent duplicate games. Shared Scottish scope rules restrict home teams.

- Football league logos use CDN asset pointers and a neutral display treatment in the sport overview, keeping brand imagery independent of navigation data and aligned with the site palette.

- Desktop grouped navigation is anchored to the full navbar with viewport-bounded scrolling and three equal group columns containing two-column link lists; compact navigation below the desktop breakpoint uses consistent heading dividers and touch targets to prevent clipping as leagues and teams grow.
